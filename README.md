# Project Star — PlayCanvas browser game proof

A browser-native endless runner prototype built directly with the PlayCanvas engine.

## What this proof tests

- browser-native 3D rendering
- procedural city/environment geometry
- endless world recycling
- lane switching and jumping
- obstacle collisions
- collectible coins
- mobile swipe controls
- keyboard controls
- realtime FPS counter
- Vercel-compatible static deployment

## Controls

- Left / Right arrows or A / D: change lanes
- Up arrow / Space / W: jump
- Mobile: swipe left/right/up

## Deployment

Static site. Vercel can deploy the repository root directly.
